# Web fetch fallback

1. Try WebFetch or curl.
2. On 403, a challenge page or empty content, open the page in headless Chrome. Read the text and take a screenshot.
3. Keep the screenshot as evidence (for example a competitor's pricing).
4. If the headless browser also fails, write "Not checked" with the URL. Do not guess.

- For questions about real-world experience, search Reddit and forums too, not only vendor docs.
- When a task limits the tools you may use, follow the limit.
