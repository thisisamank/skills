
# Section and component references

## How to use
1. Name the part: "pricing with 3 tiers and a yearly toggle", "footer with 4 link columns", "animated CTA button".
2. Sections: open the gallery for that section type, pick one example that fits the page's reference (from `landing-page-inspiration`), take a screenshot.
3. Components: find one in a library. Prefer one with "Copy prompt" or copy-paste code. Read the code before you use it.
4. Adapt it to the project's tokens (fonts, colours, radius, spacing). A pasted component that keeps its own styles looks pasted.
5. Check the licence. Many libraries mix free and paid.
6. Apply `ui-rules`. For library picks (toasts, drawers, command menus) use `pick-ui-library`.

## Rules
- One showy component per page is enough. Three is a template.
- Effects must not hurt load time on a mid-range phone. Check with `motion/animation-performance`.
- Every animated component respects `prefers-reduced-motion`.
- Do not ship a component you have not read.
