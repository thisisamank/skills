
# Motion references

These are for ideas and prompts. To build the motion well, use `motion/animate` (web), `motion/choreograph` (groups), `motion/gestures` (drag and swipe), `motion/animate-expo` (React Native). If you do not know the name of an effect, use `motion/animation-vocabulary`.

## How to use
1. Decide if the thing should move at all (see `motion/animate`). Motion needs a purpose: feedback, orientation, or brand.
2. Find one reference clip or demo. Many sites below give a prompt or a code block for Claude.
3. Rebuild it with the project's easing and durations. Do not paste a large animation library for one effect.
4. Check `prefers-reduced-motion` and frame rate on a mid-range phone (`motion/animation-performance`).

## Rules
- A background animation is subtle: low contrast, slow, and it stops when off screen.
- Scroll-jacking and heavy 3D only when the client's brand needs it (launch, luxury, studio). Never on a booking, shop or form page.
- Sounds are off by default on websites, or start only after a user action, and have a mute.
- A video background needs a poster image and a small file for phones.
