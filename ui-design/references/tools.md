# Design tools and sources

Source: the website inspiration list at learnaiwithhugo.com/resources/sites.

## Start here
| Site | Use it for |
|---|---|
| [Designeer](https://www.designeer.xyz/) | Big directory of design galleries, component libraries, AI tools and resources |
| [Pinterest](https://www.pinterest.com/) | The overall vibe. Search a palette, a mood or an industry. Good with a client before you pick a direction |

## Skills and tools for Claude
| Site | Use it for |
|---|---|
| [UI Skills](https://www.ui-skills.com/) | Directory of design skills for Claude Code |
| [Taste skill](https://github.com/Leonxlnx/taste-skill) | Stops the obvious AI look |
| [Impeccable](https://github.com/pbakaus/impeccable) | Layout, spacing and small details (used by `ui-design`) |
| [Apple Design skill](https://github.com/emilkowalski/skills) | Apple's rules for clean design and smooth animation (included as the Apple guide in `design-engineering`) |
| [Jakub Krehel's skills](https://github.com/jakubkrehel/skills) | Typography, colour, layout and UI writing |
| [Refactoring UI skill](https://github.com/s0xDk/refactoring-ui-skill) | Refactoring UI design rules |
| [VibeCurb](https://github.com/Yu-369/VibeCurb) | Holds AI to your design rules |
| [Libraries.dev skill](https://libraries.dev/skill#installation) | AI-app effects like glowing borders and thinking orbs |
| [Inspo MCP](https://inspomcp.dev/) | 800+ real websites Claude can build from |
| [Refero Styles](https://styles.refero.design/) | 2,000+ design systems from real sites, as files for Claude Code |
| [DesignMD](https://designmd.me/) | Paste a website, get its colours, fonts and spacing as a file |
| [Screenshot to Code](https://github.com/abi/screenshot-to-code) | Turn a screenshot into code |
| [Firecrawl](https://www.firecrawl.dev/) | Pull text, branding and data off a website (for example a client's old site) |
