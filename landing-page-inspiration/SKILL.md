# Landing page inspiration

## How to use
1. Read the product: who buys it, what it does, the tone (calm, technical, playful, premium), and how many features it has.
2. Pick **one** primary reference from the list that fits. You can take one detail from a second reference. Do not mix more than two.
3. Open the reference in a headless browser. Take screenshots of the hero, one feature section, pricing and the footer. Do not work from memory.
4. Tell the user which reference you picked and why, in one or two lines.
5. Hand the reference and screenshots to `impeccable`. Copy the structure, rhythm and quality bar. Do not copy the reference's text, logo, product name or images.
6. Apply `ui-rules`.

## Rules
- Do not let the page grow with every feature. Trim when it gets long. One section for each main job.
- Show what makes the product different. If the page never mentions the key feature, it fails.
- Use real counts (for example items in a catalog) when they help.
- Add a subtle background animation and small motion. Keep it clean.
- No personal details on the page.
